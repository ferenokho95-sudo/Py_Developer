# База уязвимостей

Программа хранит сведения об уязвимостях продуктов в SQLite. Позволяет проверить конкретную версию и найти версии без известных уязвимостей по данным базы.

## Файлы

- `vulndb.py` — запуск программы и выбор команды.
- `importer.py` — чтение JSON и загрузка данных.
- `commands.py` — команды `safe` и `check`.
- `database.py` — подключение к базе и SQL-запросы.
- `versions.py` — сравнение версий и проверка диапазонов.
- `schema.sql` — структура таблиц и связи между ними.
- `base.db` — база данных по умолчанию.
- `vulnerabilities.json` — сведения об уязвимостях.
- `versions.json` — список версий продуктов.

`vulndb.py` вызывает проверку из `commands.py`, которая использует `database.py` и `versions.py`.
Загрузка данных запускается отдельно через `importer.py`.

## Запуск

Нужен Python 3. Дополнительные библиотеки устанавливать не требуется.
JSON-файлы находятся в архиве `feed.7z`, пароль — `clean`. Распакуйте их в папку `data` внутри проекта.

Загрузить данные в базу:

```powershell
python importer.py
```

Найти самую новую версию без известных уязвимостей:

```powershell
python vulndb.py "PostgreSQL"
```

Проверить конкретную версию:

```powershell
python vulndb.py "Google Chrome" 132.0.6834.83
```

Получить справку:

```powershell
python vulndb.py --help
```
